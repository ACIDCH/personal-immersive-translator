基础设置

网页阅读模式与交互

参照成熟沉浸式阅读交互重新组织设置。只有启用后功能才会生效；未配置翻译服务时不执行伪翻译。

快捷键 Alt+A：翻译/恢复；Alt+W：整页翻译。Chrome 允许在扩展快捷键管理页重新设置。网站例外规则优先于自动翻译。

常规翻译凭据

PIT 云端模型需要先部署 Cloudflare Worker，并绑定 Workers AI。未部署时不能使用；本模式不要求本机 Python。

云端 PDF 翻译服务

该服务是独立的 BabelDOC 云容器，不是 Worker 地址。尚未部署前不可用；使用云算力与翻译模型可能产生费用。

AI 翻译凭据

不会自动调用 AI，也不会将密钥保存到 GitHub 或 Google Drive。

自定义 AI 服务商与模型

支持 OpenAI 兼容 Chat Completions 服务（OpenAI、OpenRouter、DeepSeek、Qwen、GLM、Groq 等）和 Anthropic Messages 协议。可以增加多个配置、选择当前模型；调用成本以对应平台为准。

自定义模型不会自动调用。先创建并选中模型，然后保存整个设置。

隐私及站点规则

API Key 保存在 chrome.storage.local，不使用同步存储。浏览器本地扩展存储本身不是端到端加密保险箱，不建议在共用设备输入生产级高权限凭据。

偏好设置导入与导出

仅导出语言、阅读样式、站点规则和常规偏好；**不导出任何 API Key、Token、自定义模型凭据或翻译记录**。导入只填入表单，须点击「保存设置」后才生效。
