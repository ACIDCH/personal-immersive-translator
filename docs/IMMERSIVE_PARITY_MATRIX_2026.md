## 状态定义

- **缺失：** 当前产品不提供。
- **原型：** 代码路径存在，但没有合格真实验收。
- **模拟通过：** MV3/Playwright 或单元测试执行成功，外部响应/平台由测试替代。
- **真实通过：** 实际供应商+实际网站/文件得到可检查的合格结果。
- **阻断：** 无法达到参考软件实用能力，不得放入正式发行清单。

## 5. 服务、迁移、质量、发版

- 标准 MT **必须有实际可用的默认服务**，不能预设一个没有 Token/额度的云端占位 Worker。
- 云端模型和 PDF 引擎跨设备使用，不要求每台 Windows 都安装 Python；用户自有云服务器需要考虑配额、响应成本与断线恢复。
- AI 只由用户明确启用，默认常规 MT；Gemini/DeepSeek/自定义兼容端点真实有效性必须逐个确认。
- 层级：L0 编译 → L1 Mock 浏览器 → L2 公开真实网页+真实外部译文 → L3 授权真实视频/复杂 PDF/图片 → L4 连续使用和发行；任一核心阻断未通过不得做 stable 安装包。
- 许可：GPL 的 KISS Translator/Read Frog/FluentRead 或 AGPL 的 BabelDOC 代码复用须遵守各自许可，不允许只复制 UI 或把 GPL/AGPL 内容标成 MIT。官方沉浸式翻译产品前端/专有核心不是可直接复制的仓库。
- 真正“和沉浸式翻译同标准”的判定需要**功能完成率、语言准确率、翻译覆盖率、网页效果、字幕同步、文档保真、延迟和异常恢复**，且至少同等用户体验。星数、代码量、模拟 CI 与页面看起来相似均不构成达标。

**本矩阵为验收清单，不是完工报告。** 只在 L4 实际验收完成后才进行自有 PIT 外观/网站品牌定稿、发布与推广。

## 2026-10-18 后续核心可靠性补丁（实际功能，不等于 L3 达标）

- 网页分批：生产翻译接口单段最大 4000–5000 字、总批次 12000 字；此前固定 6 段可能超过上限导致整个页面翻译中断。现在前端预先把单段控制在约 3200 字、每批累计控制在 9500 字以内；长段落可多次请求重组。已加入 Chromium DOM 真实执行、Mock 服务严格拒绝超长请求的回归。
- 翻译服务配置：默认 Cloudflare Worker 尚未部署时，阅读主题、语言和站点规则**仍可保存**；自动站点只有常规引擎配置完成才发起文本翻译，报错不再表现成“默认已经可用”。配置完成不等于实际外部服务可用。
- 划词卡片：增加可关闭的浮层，显示原文/译文；点击可复制译文或使用浏览器 TTS 朗读原文/译文。不是翻译字典、不提供专业发音评分。
- 设置备份：允许导出非敏感阅读语言与站点规则为版本化 JSON；不包含 API Keys、云端 Token、AI 模型密钥或翻译缓存。导入只预览并明确要求再保存。
- 站点规则：控制面板当前站点可一键加入或移除自动翻译/禁止翻译列表，两者互斥；先前仅支持手动输入。
- **后续阻断：** 实际云端翻译服务部署、正版视频网站和字幕覆盖、高保真 100+ 页学术 PDF、真实照片 inpainting/漫画、会议、面向不同浏览器的用户验收。模拟 CI 全绿不能改变此判定。

## 2026-10-18 P0-B/P0-C 运行可靠性补丁（不构成真实平台验收）

- 视频字幕：已支持在 YouTube/Bilibili/Netflix/Panopto 等明确适配的平台，发现可访问视频但暂未出现字幕时保持**等待原文 CC**，不提前发送无字幕的 MT/AI 请求。原文字幕出现后开始翻译，关闭字幕后清空显示。仅以真实安装 Chromium + 受控 DOM/Mock MT 验证延迟字幕；真实登录视频网站仍为 BLOCKED。
- 同一时间的多条原生字幕：字幕核心新增最多 3 条同时有效字幕的去重显示；避免双人同时说话时只显示最后一条。单元测试及 Chrome MV3 受控 TextTrack 回归；仍需真实 seek/倍速/多轨播放器人工验收。
- 高保真 PDF：文件工作台上传前要求已配置云容器的 `GET /health` 明确报告 `ready=true`，服务未配置、未就绪或文件超限时不上传；返回的下载内容还须为 PDF MIME 类型、满足基本体积并具有 `%PDF-` 文件签名。由模拟 HTTPS 容器 + 真正安装的 Chrome MV3 扩展测试验证，**并非实际 BabelDOC 布局、OCR、文本层保真或生产部署测试**。
- 后续阻断：真实云容器与 Whisper 部署、10/50/100+ 页复杂论文 L3、人机授权的视频网站/账户、图片漫画补绘、会议与跨浏览器长期稳定性。PR #55 保持 Draft，不合并 main。
