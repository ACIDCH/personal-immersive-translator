## 当前控制面板

打开插件图标后，以分组方式呈现：
1. 翻译模式：标准 / AI；当前服务名称和本机是否填写该服务凭据（明确提示“未验证 API 连通性”）。
2. 网页与划词翻译：翻译当前网页、翻译选中文本、恢复原文和显式授权继续 600 段。
3. 视频字幕翻译：启停、SRT/VTT 导入、平台局限说明。
4. 图片 OCR 与 PDF：打开专门文件工具，或主动捕获可见页面截图。
5. 实时语音翻译：本机 token，开始/停止，数据流隐私提示。
6. 底部操作状态/故障信息，方便用户知道是否发出请求。

## 当前设置页面

按「基础语言、常规服务、AI 服务、隐私规则、保存与测试」快速跳转。支持源语自动检测及 zh/en/ja/ko/fr/de/es 七种目标语言；微软/Google/DeepL/LibreTranslate 的凭据；Gemini/DeepSeek 模型、术语、AI 上下文；禁止翻译站点、清缓存与服务测试。该页面只配置远程翻译服务，本机 Whisper/BabelDOC/Tesseract/OCRmyPDF 通过文件工具的服务诊断另行检查。

## 发布前强制验收

GitHub Actions 的 Node、真实 Chrome MV3、模拟播放器、Tesseract、PDF.js 和 Python 桥接测试不能替代 Netflix/Panopto 授权环境。未完成真实 Whisper 30 分钟推理、BabelDOC 复杂 PDF 排版和商业翻译 API 质量/费用验收之前，不要把产品标为正式完整版本。

按用户指示，开发阶段只保留 GitHub 分支、Draft PR、CI 和文件记录；**不再每轮生成或交付插件安装包**。最终综合验收和 Codex 独立审计通过以后才准备可安装正式包。
