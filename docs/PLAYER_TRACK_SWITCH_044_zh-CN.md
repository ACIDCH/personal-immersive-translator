# v0.4.4 播放器字幕轨切换与重载防护

日期：2026-10-16。此版本集中在原生 HTML5 TextTrack 兼容性；暂不开展面板视觉重设计或最终安装包。

## 修复项

1. 用户切换原生字幕语言后，在下一次定时刷新识别新的 showing 轨道；重置翻译缓存、未完成请求状态和错误重试等待。旧轨道延迟返回的翻译不会覆盖新字幕。
2. 仅还原插件主动从 disabled 设置到 hidden 的字幕轨状态；不能因旧轨道结束而覆盖用户主动选择的新语言。
3. 原有轨道没有有效 cue 时主动清除已显示的译文，避免字幕关闭/轨道清空后留有上一句。
4. 视频节点被播放器替换，或初始非空媒体 URL 被新视频源替换时，自动停止翻译，防止在新视频上显示旧字幕。
5. 普通顶层播放器也记录首次启动时的网页 URL（去除 fragment），SPA 视频切换需用户重新确认启动；嵌入播放器继续沿用 v0.4.1 的精确录像 URL 授权。

## 验收

- `tests/player_compat_e2e.py` 增加真实无头 Chrome 中的原生字幕轨切换、旧翻译请求延迟、视频节点替换、同页路由变化等合成媒体 DOM 场景。
- 继续全量执行原有 Node、MV3、OCR/PDF 和平台模拟网页 CI。

## 未验证内容

尚无 Netflix/Panopto 真实登录播放器或 YouTube A/B 版本的账号场景验证；真实媒体 DRM、CDN、字幕格式和设备延迟不在本轮模拟测试范围内。仍保持 Draft PR，不合并 main、不发布中间安装包。
