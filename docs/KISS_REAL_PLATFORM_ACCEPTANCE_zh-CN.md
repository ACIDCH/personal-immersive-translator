# 真实平台验收指南：本人登录与本地检查

本指南适用 Draft PR #33 的 v0.4.8 实验集成。它不是正式发布版本；不要求分享登录凭据，也不向 ChatGPT 自动上传任何诊断材料。

## 在 Windows 上建立个人实验包

安装 Node.js 22.13+、Git for Windows、PowerShell 和 Chrome/Edge。在本 PR 分支的项目根目录运行以下命令：

    powershell -ExecutionPolicy Bypass -File .\scripts\build-kiss-personal-poc.ps1

脚本从公开仓库检出固定 Git SHA a1279f2517bd478ef1dd93b941f9177094486cd4 的 KISS Translator v2.1.1（GPL-3.0），再本机编译官方 Chrome 版，并将个人 MIT 文件/视频模块与 Mozilla PDF.js（Apache-2.0）加入构建目录。生成目录位于 .local-kiss-poc/kiss-upstream/build/chrome，已经加入 .gitignore。脚本不生成可公开分发的 ZIP，不覆盖仓库 main，也不会读取或保存浏览器登录凭据。

打开 chrome://extensions 或 edge://extensions，开启开发者模式，点击“加载已解压的扩展”并选择该 build/chrome 目录。请优先使用独立的浏览器用户资料测试，避免与原有扩展冲突。首次安装需要你自己在浏览器权限界面授权网站访问。若 .local-kiss-poc 已存在，脚本会直接拒绝覆盖；请自行检查原目录再处理。

## 在本人授权的平台执行验收

1. 在自己的浏览器登录 O2B、Panopto 或其他你有权访问的平台，打开视频并播放一段，检查平台自带字幕。
2. 在 KISS 弹窗中点击“视频字幕 / Whisper”，保持标准翻译模式，尝试开启增强字幕。选取可见的测试视频；无需发送课程链接、姓名、邮箱或字幕文本。
3. 进入“真实网站兼容性检查”，选择平台，依次记录视频、原文字幕、双语字幕、全屏及 Whisper 是否正常。对未安装本机模型或未测试的项目选择“未测试”。
4. 点击“检查当前网页播放器”。工具仅计算 HTML5 video、TextTrack、可见字幕候选节点及 iframe 的数量，不读取字幕文字或媒体来源链接；在受到跨站框架限制时尝试只检查主框架，并将限制写入报告。
5. 点击“导出不含敏感内容的诊断 JSON”。文件只保存在自己的设备。先自行打开检查，如愿意，可将 PIT-site-check.json 上传至本聊天，便于基于真实页面的结构修复适配器。

## 隐私与验收边界

诊断 JSON 包含选定平台类型、通过/失败/未测选项、聚合数量和扫描限制标记；不包含网页 URL、课程标题或正文、账号信息、字幕原文、密码、Cookie、API 密钥、完整视频路径和媒体流。工具不会录屏，也不自动上传。真实语音识别需另行安装并运行带 token 保护的本机 Whisper 服务。已登录站点可能有合法的 DRM 或访问限制，不能绕过。完整组合包作为 KISS 派生构建保留 GPL-3.0 相关义务。

如果遇到插件无法加载，请先查看扩展管理页面的错误信息，分享去掉账号/路径细节的错误描述即可，避免发布含会话信息的截图。
