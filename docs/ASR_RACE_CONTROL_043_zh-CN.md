# v0.4.3 实时语音字幕启动/停止竞态与旧会话隔离验收

日期：2026-10-16。仅增强 ASR 会话可靠性，不进行品牌或控制面板最终设计。

## 本轮新增

1. **后台串行化**：使用单一 Promise 链顺序处理用户 START、STOP、旧音轨结束和同标签页关闭/加载事件。排队执行的结束通知在操作开始时再次确认 UUID，避免错误终止重启后的识别。
2. **网页字幕隔离**：所有由 offscreen 转发的字幕/状态消息以及启动/停止命令都带 sessionId。网页侧只接受当前录音的状态，旧会话的 STOP 和报错无法清除新会话覆盖层。
3. **跨代异步请求**：实时字幕的请求占用标记随会话 epoch 更新。旧翻译请求仍在途时，新会话可开始新的标准翻译，旧结果不再显示。
4. **避免停止后远端调用**：对于临时 ASR 文本翻译，后台验证 sender.tab.id 和当前 sessionId，旧录音不能在用户停止后新发起翻译。
5. **关闭/导航清理**：捕获当前 session ID 后排队清理，执行前再校验身份，避免旧网页加载事件误关新会话。

## CI 验收范围

- `tests/asr-control-race.test.js`：并发启动/停止、关闭前旧会话与正确新会话。
- `tests/live_caption_e2e.py`：真实 Chromium DOM、延迟 mock 提供方的跨会话翻译、旧 STOP/旧字幕及停止后 UI 清理。
- 继续运行既有所有 Node、Chromium、PDF/OCR 回归。

边界：无真实流媒体账号、无真实麦克风、无 Whisper 模型长期实机和商业 API 扣费；模拟测试不能替代 Windows 30 分钟实机。继续保留 Draft PR，不合并 main。
