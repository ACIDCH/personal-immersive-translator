## 当前明确限制

1. Netflix 的 DRM/账号以及私有字幕协议不能绕过；Panopto LMS 只有在用户有课程权限、明确授权 iframe 目标域名、字幕可见时才能处理。权限被拒绝或播放器更换来源时应显示错误，而非隐蔽抓取。
2. 真实 30 分钟多语言 Whisper、CPU/GPU 使用率、GPU/驱动适配和断网恢复仍待实机测试。AudioWorklet 结构降低主线程音频处理负担，但不能以此直接断言已达到 p95 ≤ 8s。
3. BabelDOC 仍是独立安装的 AGPL-3.0 程序及 DeepSeek 等用户自有兼容 API；当前 CI **没有真正调用 BabelDOC 完成复杂论文翻译**，只证明请求、配置、OCR、有效输出合同。公式、表格、双栏的翻译后逐页视觉对比仍为正式发布阻断项。
4. 语言包安装检查不能证明中文、英文、日语、韩语、法语等具有相同 OCR 准确率。需要后续用人工标注样本统计 CER/WER。
5. 没有和现有沉浸式翻译软件取得同环境量化对照之前，不宣称更高翻译准确率或更好性能。
