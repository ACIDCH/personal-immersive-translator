# v0.4.2 实时语音会话与停止通知修复

日期：2026-10-16。仅修复运行时，不涉及整体面板重新设计。

## 实施内容

1. 每次明确启动 ASR 时生成新 UUID，发送给已授权的 offscreen 本地音频上下文。识别结果、错误、性能指标和录音结束事件都携带该会话标识。
2. 后台只有同时匹配 **tabId 和 UUID** 才接受 offscreen 消息。取消录音时先清除会话存储，后断开流，避免旧结果污染新录制。
3. 在本机音频启动前注册会话，并在显示“运行中”前再次核对状态，防止早期音频断流时的虚假状态。
4. 达到 **1,440 次识别请求** 的限额后自动停止，并向后台发送结束通知以清除显示状态。此数为识别请求次数，不是精确 72 分钟计时。
5. 旧会话结束消息不可停止同一标签页上的新会话；仍不缓存原始音频或在云端存储文字。

## 回归证据

- `tests/background-asr-session.test.js`：启动流程、旧事件隔离、合法结果转发、自动结束与存储清理。
- `tests/live-pipeline.test.js`：上限前后边界。
- 持续沿用现有 Chrome 播放器、字幕及 PDF/OCR 自动化测试。

自动化测试采用虚拟标签页和本地假数据，不等于在真实 Windows 机器执行多语种 Whisper 或真实视频网站的长期稳定性验收。阶段性 PR 保持 Draft；不合并主分支、不交付中间安装包。
